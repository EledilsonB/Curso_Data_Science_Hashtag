# Titanic - Curso de Ciência de Dados | Hashtag Programação

Projeto desenvolvido durante o curso de Ciência de Dados da **Hashtag Programação**, utilizando o clássico dataset do **Titanic** (Kaggle).

## Sobre o Projeto

Utilizando o dataset `train.csv`, este projeto tem como objetivo prever a sobrevivência dos passageiros do Titanic com base em características como idade, classe social, sexo, entre outras variáveis.

Durante o desenvolvimento, tive a oportunidade de ampliar minhas habilidades em:
- Análise Exploratória de Dados (EDA)
- Tratamento e limpeza de dados
- Treinamento e comparação de modelos de classificação:
  - K-Nearest Neighbors (KNN)
  - Decision Tree
  - Logistic Regression

## Ferramentas Utilizadas

- **Python**
  - Pandas
  - Matplotlib
  - Seaborn
  - Scikit-Learn

## Base de Dados

Dataset: [Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic) (Kaggle)

Arquivo utilizado: `train.csv`
